# Thư mục Resources

Chứa các lớp định nghĩa Custom Resource (data-driven) và các file dữ liệu cấu hình `.tres`:

- `class_data.gd` / `skill_data.gd`: Các lớp định nghĩa dữ liệu (chỉ chứa `@export var` và logic phụ trợ).
- `classes/`: Chứa 6 file `.tres` tương ứng cho 6 class nhân vật.
- `skills/`: Chứa các file `.tres` của các kỹ năng trong game.
