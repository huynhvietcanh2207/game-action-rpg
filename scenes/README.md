# Thư mục Scenes

Chứa các Scene cấu thành game trong Godot 4:

- `player/`: Scene của người chơi (Player.tscn).
- `enemy/`: Các mẫu quái vật và Boss.
- `ui/`: Các thành phần HUD, Menu và Dialogues.
- `map/`: Các màn chơi (Level) và bản đồ thử nghiệm (MapPlayground.tscn).
- `systems/`: Các Scene quản lý hệ thống game (Spawner, QuestManager, CombatLogs).
