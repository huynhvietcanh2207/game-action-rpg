# Thư mục Assets

Thư mục này dùng để chứa toàn bộ tài nguyên đa phương tiện của dự án.

## Cấu trúc đề xuất:
- `sprites/`: Chứa các sprite sheet, hình ảnh nhân vật, quái vật, hiệu ứng (pixel art).
- `tilesets/`: Chứa các hình ảnh gạch nền bản đồ (tilesets) để vẽ địa hình.
- `audio/`: Chứa nhạc nền (bgm) và hiệu ứng âm thanh (sfx).
