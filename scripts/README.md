# Thư mục Scripts

Chứa mã nguồn GDScript điều khiển các module và scene tương ứng:

- `player/`: Logic của người chơi (di chuyển, tấn công, quản lý thanh trạng thái).
- `enemy/`: Logic AI quái vật, boss (sử dụng LimboAI hoặc Finite State Machine).
- `ui/`: Các thành phần giao diện người dùng (HUD, Menu chọn class, Inventory).
- `map/`: Mã nguồn điều khiển bản đồ, spawn quái vật, chuyển cảnh.
- `systems/`: Các hệ thống quản lý cơ chế game (Combat, Quest, Loot, Crafting).
